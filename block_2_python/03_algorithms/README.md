#  Алгоритмы

Реализация трёх алгоритмов из книги «Грокаем алгоритмы»

## `quick_sort.py`

Быстрая сортировка

* Опорный элемент - первый элемент списка
* Остальные числа делю на `low` (меньше или равны pivot) и `high` больше
* Сортирую обе части с помощью рекурсии,собираю их воедино
* Генерирую список из 60 чисел

## `binar_search.py`

Бинарный поиск в отсортированном массиве

* Функция `binar_search` ищет элемент в отсортированном списке целых чисел
* Массив из 30 элементов 
* На каждом шаге сравниваю середину с выбранным числом и отбрасываю половину массива


## `BFS.py`

Поиск в ширину - кратчайший путь в графе

* Граф задан словарём, человек-список знакомых (22 вершины)
* Очередь `deque` - сначала ближайшие,потом соседи
* Словарь `came_from` запоминает от кого пришли,чтобы восстановить путь
* Функция возвращает список вершин кратчайшего пути или None
