1.2 Методы работы со строками и словарями


Задание 1 (Подсчет частоты слов) 
Перевел весь текст в нижний регистр,чтобы регистр не влиял на подсчет.
Через цикл и проверку isalpha() очистил текст от знаков препинания,заменив их на пробелы,разбил строку на слова.
Прошелся циклом по списку слов и закинул их в словарь: если слово уже было-увеличивал счетчик, если нет-добавлял с единицей.


Задание 2 (Проверка на палиндром) 
Сначала привел строку к нижнему регистру.
Создал пустую строку и через цикл закинул туда только буквы.
В конце просто сравнил получившуюся чистую строку с её перевернутой копией через срезы [::-1]. Если равны-палиндром.
