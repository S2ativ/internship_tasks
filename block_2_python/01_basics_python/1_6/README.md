## Задание 2
* создаю массив из дней от 0 до 9999 (10000 элементов)
* создаю массив значений температур: "temp = 15 + 10 * np.sin(days * (2 * np.pi / 365)) + np.random.normal(0, 2.5, 10000)"
  * 15 — базовая температура года
  * 10 * np.sin(days * (2 * np.pi / 365)) — синусоида с периодом 365 дней, размах +-10 градусов
  * np.random.normal(0, 2.5, 10000) — случайное нормальное распределение (шум)
* дальше вычисляю обычную статистику
* чтобы найти самую длинную серию:
  * перевожу массив в бинарный вид, где 1 — это температура ниже среднего, 0 — выше
  * складываю три массива (ставлю по границам нули), чтобы гарантированно закрыть серии
  * вычисляю разность между каждым след и пред элементом: 1 соответствует о начале холодной серии, -1 — это конец серии, 0 — погода не меняется
  * нахожу индексы стартов и концов серий холода, нахожу максимальную разность и вывожу ответы
