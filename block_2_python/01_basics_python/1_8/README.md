# 1.8. Циклы for и while

## Задание 1
* импортирую библиотеки random и string
* запрашиваю у пользователя тип пароля и его длину
* через условия формирую пул доступных символов из наборов string
* с помощью цикла for и random.choice собираю пароль заданной длины
* вывожу пароль

## Задание 2
* задаю начальный баланс
* запускаю бесконечный цикл while True и вывожу меню
* считываю выбор пользователя
* если "пополнить" - запрашиваю сумму и прибавляю к балансу
* если "снять" - проверяю,достаточно ли денег,если хватает - уменьшаю баланс,иначе отменяю операцию
* если "баланс" - вывожу текущее значение
* если "выход" - останавливаю цикл с помощью break
* если введена неизвестная команда - сообщаю об ошибке и возвращаю в меню
