Задание 1 словарь для слов с одинаковымы первыми буквами
создаю пустой словарь
прохожусь по каждому слову через цикл for
беру первую букву слова и смотрю,есть ли она в словаре.если нет-значит она встретилась впервые-тогда я создаю для этого ключа пустой список,а затем уже добавляю к списку это слово

Задание 2 подсчет частоты символов
создаю пустой словарь
прохожусь по каждому символу строки 
если нет символа в словаре- для этого символа(ключа) значение будет 1,если же символ встретился n-ый раз,то значением уже будет '(n-1)+1' , т.е. 'n'
