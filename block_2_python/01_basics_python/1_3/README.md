# 1.3. Списки и списковые включения (List Comprehensions)

## Задание 1 (Удаление отрицательных чисел и сортировка остававшихся с помощью спискового включения)
* Преобразую введенную строку в список чисел через списковое включение
* С его же помощью отсеиваю отрицательные числа
* Сортирую список отфильтрованных чисел и вывожу результат

## Задание 2 (Замена элементов)
* Проверяю длину списка и вывожу соответственный результат
